# Module 01 - Introduction to Data Visualization

## Labs

- **Lab01** - Exploring and pre-processing a dataset using Pandas
- **Lab02** - Introduction to Matplotlib and line plots

## What this module covers

Loading a dataset into a DataFrame and inspecting its shape, columns and data types;
handling missing values; selecting, filtering and grouping data; then producing the
first plots with Matplotlib - figure and axis objects, line plots, titles, axis labels,
legends and annotations.

## Key techniques

- `pd.read_csv`, `df.info()`, `df.describe()`, `df.isnull().sum()`
- Missing-value imputation: mode for categorical attributes, mean for continuous ones
- Type conversion with `astype`
- `plt.plot`, `plt.figure`, `plt.subplot`, and axis-level formatting
