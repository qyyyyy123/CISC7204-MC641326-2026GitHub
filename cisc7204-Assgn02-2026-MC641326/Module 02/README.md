## What this module covers

The standard chart family used to compare categories, show distributions and reveal
relationships: area plots for cumulative change over time, histograms for distributions,
bar charts for comparison, pie charts for composition, box plots for spread and outliers,
and scatter and bubble plots for relationships between two or three variables.

## Key techniques

- `df.plot(kind='area' | 'hist' | 'bar' | 'pie' | 'box' | 'scatter')`
- Binning and transparency in histograms
- Bubble size and colour encoding a third variable
- Direct Matplotlib calls as an alternative to the Pandas plotting interface
