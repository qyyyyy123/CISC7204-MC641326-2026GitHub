# Module 05 - Practice Project

## Labs

- **Lab01** - Analyzing wildfire activities in Australia
- **Lab02** - Creating dashboards

## What this module covers

A complete practice project on a real dataset: wildfire activity records covering the
Australian regions, including the annual fire raster area and the reported cause. The
first lab cleans and aggregates the data and builds exploratory visualizations; the
second turns the analysis into an interactive dashboard so that a non-technical audience
can explore the pattern themselves.

## Key techniques

- Reading and cleaning the wildfire dataset, parsing dates and extracting year and month
- Grouping by region and year to compare fire area over time
- Interactive Plotly charts and a Dash layout with dropdown and radio-item controls
- Callbacks connecting the selected region to the displayed charts
