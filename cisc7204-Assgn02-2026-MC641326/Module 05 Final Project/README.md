# Module 05 - Final Project

## Labs

- **Lab01** - Visualizations with Matplotlib, Seaborn and Folium
- **Lab02** - Creating a dashboard using Plotly and Dash

## What this module covers

The capstone of the visualization sequence. The first lab combines the three libraries
used across the course - Matplotlib for fine-grained control, Seaborn for statistical
plots with less boilerplate, and Folium for geospatial layers - to build a set of static
exhibits that tell a coherent story. The second lab rebuilds the same story as an
interactive dashboard, so that the audience can filter and drill into the data rather
than only reading a fixed narrative.

## Key techniques

- Matplotlib figure composition: multiple axes, shared scales, annotations
- Seaborn: `heatmap`, `pairplot`, `catplot`, `regplot`, `distplot`
- Folium: marker clusters, choropleth layers and layer control
- Plotly and Dash: interactive charts, layout components and callbacks
