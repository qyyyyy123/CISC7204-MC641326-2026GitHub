# Module 03 - Advanced Visualizations and Geospatial Data

## Labs

- **Lab01** - Waffle charts, word clouds and regression plots
- **Lab02** - Creating maps and visualizing geospatial data

## What this module covers

Visual forms that go beyond standard charts: waffle charts as a readable alternative to
pie charts for part-to-whole comparisons, word clouds for text frequency, and regression
plots that show a fitted relationship together with its uncertainty. The second lab moves
to maps - choropleth maps colour-coding regions by value, and marker maps placed by
latitude and longitude.

## Key techniques

- Waffle chart construction with Matplotlib subplots
- `WordCloud` generation and frequency counting
- `seaborn.regplot` for fitted relationships
- `folium.Map`, `folium.Choropleth`, `folium.Marker` and GeoJSON boundaries
